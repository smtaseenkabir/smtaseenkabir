## ⚡ About Me

I'm a science student from Bangladesh who treats every project like a small proof that the plan is working. By day I'm preparing for **HSC 2027**; by night I'm shipping real web products, poking at Linux internals, and drafting chapters of my own novel — three completely different disciplines that all come down to the same skill: finishing what you start.

- 🎯 **Long game:** Fully-funded scholarship abroad → Computer Science / Software Engineering
- 💼 **Right now:** Freelance & personal projects in **Next.js**, **React**, **TypeScript**, **Three.js**
- 🛡️ **Side quest:** Cybersecurity fundamentals, Linux systems, ethical hacking concepts
- 📜 **Credentials:** EC-Council · Great Learning Academy · Harvard **CS50** (in progress)
- ✍️ **Off the keyboard:** Writing *"21 Letters I Never Sent"* — an epistolary novel
- 🧠 **Philosophy:** *Ship to learn.* Theory doesn't count until it's deployed.
